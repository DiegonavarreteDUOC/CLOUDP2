# Frontend — Mini Pedidos Dashboard
**Evaluación Parcial N° 3 — Desarrollo Cloud Native I (DSY1107) — Duoc UC**

Aplicación web React + Vite con autenticación OAuth 2.0 / OpenID Connect mediante **AWS Cognito (IDaaS)** y consumo de endpoints backend protegidos por JWT.

---

## 🚀 Características

- **Autenticación IDaaS:** Login con AWS Cognito User Pool (`amazon-cognito-identity-js`), generación de JWT seguro.
- **Gestión de Pedidos:** Formulario para registrar nuevos pedidos y visualización en tiempo real del listado y métricas.
- **Interfaz Moderna:** Diseño modular basado en Bootstrap con paleta oscura profesional.

---

## 🛠 Instalación y Ejecución

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev
```
